# fonts

设备界面用的展示字体(经 LittleFS 加载,M5GFX `ft_ttf`):

- `PokemonClassic.ttf` —— 宝可梦 GB 游戏(1/2 世代)战斗文字复刻,
  作者 TheLouster115,来源 [dafont](https://www.dafont.com/pokemon-classic.font)(100% Free)。
  当前用于倒计时/时钟数字。
- `PokemonSolid.ttf` —— 宝可梦 logo 体复刻,来源
  [dafont](https://www.dafont.com/pokemon.font)(free for personal use)。备用。

这两个字体是其作者的 fan-made 作品,不属于本仓库代码的许可证覆盖范围;
如作他用请遵守原始站点的条款。

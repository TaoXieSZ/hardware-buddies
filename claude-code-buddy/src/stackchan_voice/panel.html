设置 · 写入小咪 NVS

空闲断开—
无操作多久后断开云端连接回打盹（省钱）。NVS vidle
轮数上限—
聊满这么多轮就重开会话，防上下文累积计费。NVS vturns
音量—
下限 96，再低语音就听不清了
屏幕亮度—
音色下次唤醒生效
人设 instructions下次唤醒生效
留空 = 用固件出厂人设。建议保留"回答不超过 3 句"这类硬性约束
已保存，下次唤醒建立会话时生效（当前会话不重连，避免丢上下文）

动作 · 摇头跳舞

摇头跳舞总开关
开：说话摆头、思考点头。关：安静陪伴，舵机不动。NVS motion
说话时来段舞
回答时用更起劲的摆动，而不只是轻轻摆头
待机东张西望
空闲时小幅张望。NVS idlew
抬头角度—
0°=低头看桌面，90°=仰头看你。NVS tilt

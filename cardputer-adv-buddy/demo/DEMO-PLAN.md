# Clawd 掌上 Claude Code 搭子 — 小红书 Demo 录制方案

> 配合海报 `backdrop.html`(浏览器全屏当背景,cardputer 压在中间光晕「舞台位」上)。
> 核心卖点一句话:**「你的 AI 编程搭子,有了会表情、能对话、能语音指挥的实体桌宠」**。

## 一、叙事主线(建议 30–45s,分段拍后剪辑,别一镜到底)
情绪弧:萌登场 → 它懂你写代码 → 你反向指挥 AI → 收个可爱尾。

## 二、分镜脚本(每幕:画面 / 我负责 / 你负责 / 字幕)

| # | 画面 | 我负责(喊 3-2-1 触发) | 你负责(拍) | 字幕 |
|---|---|---|---|---|
| **0 开场** 3s | clawd 在桌上 idle 卖萌,旁边是你笔记本 | 保持空闲(出 idle/sleep) | 特写设备 | 「我给 Claude Code 做了个实体搭子🐾」 |
| **1 它懂你写代码** 8s | 你给我发任务→设备 **thinking** 动画→我跑构建 **busy(敲键盘)**→完成 **celebrate** | 真做一个小任务:思考→跑命令→完成 | 同框拍**电脑屏 + 设备**,让人看到「代码在动 ↔ 它在反应」 | 「AI 在想 / 在干活 / 干完了,它全写脸上」 |
| **2 AI 问你·掌上就答**⭐ 10s | 我弹一个**中文选项**问题→设备直接显示选项→你**按数字**答→我接着干 | 我喊「拍!」后弹 AskUserQuestion(短中文选项) | 特写设备屏 + 你手指按数字键 | 「AI 反问你?不用回电脑,掌上一按就答」 |
| **3 按住说话指挥 AI**⭐ 8s | 你按住 v 说一句中文指令→Doubao 转写进终端→我照做 | 我待命接收并执行 | 拍你**按住 'v' 说话** + 电脑里文字蹦出来 + 我开始做 | 「按住说话,语音指挥 AI 写代码」 |
| **4(可选)多会话切换** 6s | 你在设备上选另一个 session→cmux 那个窗口弹到最前 | 我先开 2-3 个会话 | 拍设备选会话 + 电脑窗口**唰地切过去** | 「开了好几个 AI?掌上一键切」 |
| **5 收尾·萌** 4s | 摇一摇→**dizzy 转圈**;放下不动→**睡着** | 无 | 拍**摇设备**→晕;然后它打盹 | 「摇一摇它会晕…困了还会睡😴」 |

## 三、我俩的配合协议(关键)
- **分段拍**:一幕一条,我按你节奏来。每个由我触发的动作(第1幕状态、第2幕问题),我会先说「准备…3-2-1-发」,你卡这个点录。
- **你触发的**(按数字/按住v/摇/切会话)你自己做,我负责"接住并演下去"(比如答完我回「好,按你选的来」)。
- 拍前我们**先彩排一遍**每个触发,确认设备反应正常(connect-drop 已修+watchdog,但开拍前我仍会确认连接稳)。

## 四、拍摄小贴士
- 屏幕小:**怼近 + 补光**,中文/clawd 要清晰;第1、2幕尽量**设备与电脑屏同框**,因果关系才有冲击力。
- 开拍前**插着 USB 供电**别让它睡;我开拍前确认 BLE 连着。
- 第2幕问题选项用**短中文**(efont 一行约 20 字),别太长被裁。
